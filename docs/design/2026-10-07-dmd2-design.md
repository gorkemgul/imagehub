# DMD2 design

- Date: 2026-10-07
- Issue: #36
- Workflow: `.ai/skills/add-or-validate-image-model/SKILL.md`

## Scope

`dmd2-sdxl-4step` (`dmd2_sdxl_4step_unet.bin`) and `dmd2-sdxl-1step` (`dmd2_sdxl_1step_unet.bin`) from
`tianweiy/DMD2` (revision `be22767`, CC-BY-NC-4.0), the full float32 SDXL U-Nets, text-to-image only, at `full`
validation status, in the existing `stable-diffusion-xl` family. Out of scope: the fp16 copies (precision variants), the
4-step LoRA, the SD 1.5 and ImageNet training checkpoints, the T2I-Adapter example, fp16/bf16 parity.

## Reference

The model card's usage: `stabilityai/stable-diffusion-xl-base-1.0` with the U-Net replaced, the scheduler replaced by
`LCMScheduler.from_config(<SDXL scheduler config>)`, guidance 0, and explicit timesteps `[999, 749, 499, 249]` (4 steps)
or `[399]` (1 step), with diffusers 0.40.0 `StableDiffusionXLPipeline`. The reference loads the composite snapshot with
`StableDiffusionXLPipeline.from_pretrained`, as for Hyper-SD.

## Components

| Part | Status |
| --- | --- |
| SDXL text encoders, tokenizers, VAE | exist (from `sdxl-base-1.0`) |
| U-Net: same layout as the SDXL base U-Net (1680 float32 tensors), published as a PyTorch pickle | the `.bin` reader exists (`weights_only=True`) |
| Composite snapshot that leaves out the base U-Net weights | **new**: a catalog field for base files that the overlay replaces under a different name |
| LCM scheduler with explicit timesteps on SDXL | exists (Hyper-SD) |

## Pipeline

As for Hyper-SD, with the DMD2 timesteps. Defaults from the model card: 4 steps, guidance 0.0, timesteps
`[999, 749, 499, 249]`; and 1 step, guidance 0.0, timesteps `[399]`; both 1024×1024. The 4-step model draws LCM noise
from the generator between steps.

## Memory

As SDXL: about 14 GB in fp32 per pipeline; reference and native fit together.

## Validation

Catalog and download tests for the base-file exclusion, then for each model: header check of the overlay U-Net (read
from the pickle with `weights_only=True`), U-Net single step at 1024×1024 at the first default timestep, end to end at the
defaults (latents and pixels), the seed test, and a side-by-side sample image.
