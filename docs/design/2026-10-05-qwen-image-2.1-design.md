# Qwen-Image 2.1 design

- Date: 2026-10-05
- Roadmap step: 8 in `.ai/GOAL.md` (issue #17)
- Workflow: `.ai/skills/add-or-validate-image-model/SKILL.md`

## Scope

`qwen-image-2.1` (`Qwen/Qwen-Image-2.1`, revision `d26bb61231c349cf6b7896fa83353113880e1ba3`,
Qwen Research License), text-to-image only, at `full` validation status, as a new family
`qwen-image`. Out of scope: image editing (the `image` input, condition images, the vision encoder
of Qwen3-VL), fp16/bf16 parity.

## Reference

No released diffusers version contains this model (0.40.0, the latest release, predates it). The
reference is the implementation the Qwen team contributed to diffusers, pinned to commit
`7997e4eabb1f880fa5697e2b24de09a892fffad5` (the latest commit touching its files; later commits only
add type annotations and comments), installed in a separate reference environment
`.venv-ref-qwen-image-2.1` with the same torch (2.14.1) and transformers (5.18.0) as the main
environment. The other models keep diffusers 0.40.0. `docs/validation.json` records the reference
per model; when a diffusers release contains this model, the comparison is re-run against it.

## Published checkpoint

| Part | Notes |
| --- | --- |
| processor | Qwen2 tokenizer files (reuse `imagehub.tokenization_qwen`) + `chat_template.jinja`; the pipeline formats prompts with its own template and drops the system-prompt tokens |
| text_encoder | `Qwen3VLForConditionalGeneration`, text path only: 36 layers, hidden 4096, GQA 32/8, head_dim 128, interleaved mRoPE (sections 24/20/20, θ=5e6); the pipeline takes `hidden_states[-1]` (last layer, before the final norm); bf16, 4 shards (≈ 35 GB in fp32); vision tower tensors skipped by an explicit allow-list |
| transformer | `QwenImage21Transformer2DModel`: 32 layers, 32 heads × 128, mlp_ratio 3 (SwiGLU), patch 1, 64 channels, 3-axis RoPE 16/56/56, zero-centred RMSNorm, `causal_condition`: block-causal joint attention with a text KV cache reused across steps; bf16, 2 shards (≈ 28 GB in fp32) |
| vae | `AutoencoderKLQwenImage21`: Wan-style causal 3D VAE (base 96, decoder base 144, dim_mult 1,2,4,8,8, residual, 64 latent channels, per-channel `latents_mean`/`latents_std`) |
| scheduler | `FlowMatchEulerDiscreteScheduler` with dynamic shifting (`mu` from the image sequence length, base/max shift 0.5/0.9, seq len 256/8192), exponential time shift, `shift_terminal` 0.02 |

## Design

- **Text encoder** (`models/qwen3_vl_text.py`): the Qwen3-VL language model without the vision
  tower, with interleaved mRoPE driven by the position ids the reference builds for text-only input.
  Reuse `models/qwen3.py` building blocks where numerics are identical.
- **Transformer** (`models/qwen_image21_transformer.py`): the text-to-image path of the reference,
  including its block-causal mask and the KV cache the pipeline enables by default
  (`use_kv_cache=True`). Reproduce the attention processor the reference selects on CPU.
- **VAE** (`models/autoencoder_kl_qwen_image21.py`): decode (and encode for parity) of the causal 3D
  VAE for single images (one frame), including its feature cache.
- **Scheduler**: extend `schedulers/flow_match_euler.py` with dynamic shifting, the exponential time
  shift and `shift_terminal`, as the reference implements them; existing configs keep their numerics.
- **Backend** (`backends/qwen_image.py`): prompt formatting and system-token dropping as
  `_get_qwen_prompt_embeds`, CFG through `true_cfg_scale` (default 1.0: no CFG), negative prompt,
  latents packing, decoding with the latent statistics. Defaults: 40 steps, `true_cfg` 1.0,
  1024×1024 (`output_resolution`; the model card's 2048×2048 is an option).

## Memory and runtime

fp32: text encoder ≈ 35 GB and transformer ≈ 28 GB per copy. Component tests load one pair at a time;
end-to-end tests run the reference first in its own environment, save latents and pixels, and our
implementation then runs and compares. End-to-end tests at 1024×1024 with a reduced step count
(recorded); the seed test the same.

## Validation

Header checks (sharded), random-weight parity for each new module (tiny configs exact; full-config
layouts on the meta device), scheduler parity including dynamic shifting, prompt/token parity, a
tiny-snapshot end-to-end comparison with `QwenImage21Pipeline`, then real-checkpoint component and
end-to-end parity, CFG on and off, plus the seed test. All reference tests for this model run in
`.venv-ref-qwen-image-2.1`.
