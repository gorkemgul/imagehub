# PRX implementation plan

1. Pin both repositories and store published configs, indexes and safetensors headers.
2. Implement the PRX transformer with exact random-weight parity and a meta-device header check.
3. Implement the T5Gemma encoder and tokenizer behavior, then verify its state layout and outputs.
4. Reuse the FLUX VAE and flow-match scheduler in a PRX backend with strict option validation.
5. Add catalog, registry, documentation and snapshot-gated reference coverage for both checkpoints.
