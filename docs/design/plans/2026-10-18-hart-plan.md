# HART implementation plan

1. Pin the official HART weights, Qwen2 text encoder, and implementation revisions; store all
   published configuration/index files and exact tensor manifests as fixtures.
2. Add failing layout and random-weight reference tests for the HART transformer, residual
   diffusion MLP, hybrid autoencoder decoder, and Qwen2 text path.
3. Implement the native modules with published tensor names and strict pickle/safetensors loading.
4. Add the HART backend, official prompt encoding and deterministic multi-scale generation loop;
   cover option validation, repeatability, non-square rejection, and a tiny end-to-end comparison.
5. Add the pinned catalog entry and registry mapping, then build a local verified snapshot from the
   downloaded official files.
6. Add opt-in real-checkpoint component and public-pipeline end-to-end tests, with separate seed-0
   and seed-42 records.
7. Update the README, catalog/model/validation pages, validation grouping, and third-party notices;
   run targeted parity tests, formatting, lint, typing, the fast suite, and the clean-env suite.
