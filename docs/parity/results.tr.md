# Sonuçlar

Her checkpoint için bir satır; veriler `docs/validation.json` dosyasından alınır. Tire, ilgili
karşılaştırma biçiminin o model için kaydedilmiş kanıt olmadığını gösterir. Bazı modeller yalnızca
token ve pikseller üzerinden denetlenir; kayıtlı referans diffusers veya modelin resmî uygulaması
olabilir. Ayrıntılı açıklama [Doğrulama](../validation.md) sayfasındadır.

Ölçüm ortamı: CPU, float32, Python {{ ih.python }}, PyTorch {{ ih.torch }}, diffusers
{{ ih.diffusers }}, transformers {{ ih.transformers }}.
